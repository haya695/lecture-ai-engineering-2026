        question = args.question

            print(f"\n[質問] {question}\n")
            print(ask(chat, question))

            while True:
                question = input("\n次の質問（終了するには exit）: ").strip()
                if question.lower() in {"exit", "quit", "終了"}:
                    return
                if question:
                    break

AIE2026の講座で使用される「**lecNNタグ**」（NNには数字が入ります。例えば `lec01`, `lec05` など）は、**講義の回（レッスン）を識別するための管理用タグ（キーワード）**です。
具体的には以下のような目的や意味で使用されます。

1. **教材やファイルの整理**
   - GitHub、Googleドライブ、Notionなどの学習プラットフォーム上で、資料、サンプルコード、動画アーカイブなどを「第何回目すものか」で分類・検索しやすくするために使われます。
   - 例：`lec01`（第1回）、`lec02`（第2回）...

2. **質問やサポート時の指定**
   - 受講生がSlackやDiscordなどのコミュニティで質問する際、「`lec03`の課題でエラーが出ました」のように使うことで、講師やTA（ティーチングアシスタント）がどの回のどの内容についての質問か瞬時に把握できるようにします。

3. **カリキュラムの進行管理**
   - 自身の受講進捗（どこまで終わっているか）を管理する目印としても使われます。

もし具体的な資料やシステム（Slackのチャンネル名、GitHubのフォルダ名など）でこのタグを見かけた場合は、**「その講座の何回目の授業に関するものか」**を示しているとご理解ください。
